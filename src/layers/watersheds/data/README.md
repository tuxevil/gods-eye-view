# BasinATLAS watershed subset

Data license: **CC BY 4.0**, https://creativecommons.org/licenses/by/4.0/ .
The project's MIT license applies to code, not a relicensing of these data.

Source: https://www.hydrosheds.org/hydroatlas and the authors' release
https://doi.org/10.6084/m9.figshare.9890531.v1 .
Citation: Linke et al. (2019), Global hydro-environmental sub-basin and river reach
characteristics at high spatial resolution, Scientific Data 6:283,
https://doi.org/10.1038/s41597-019-0300-6 .

Changes: seven level-8 units selected; attribute subset; Shapefile to GeoJSON
conversion with original WGS84 coordinates; interior label anchors added. No
simplification, clipping, reprojection or inferred reservoir catchments.
The product's geometries originate in HydroBASINS v1c; this subset is extracted
from the CC BY 4.0 BasinATLAS release, not relicensed from a HydroBASINS download.

Full provenance is embedded in `paute-units.geojson`; acquisition, original input
hashes, reproduction, scope and checks are documented in
`docs/research/ecuador-watersheds-integration.md` at the repository root.
